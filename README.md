# Cursor sem segredos

Guia de estudo em português para usar o Cursor, em três níveis: básico, intermediário e avançado.

Este material é independente. Ele se apoia na documentação pública do Cursor em outubro de 2026 e não é um manual oficial.

## Abrir o livro

Na pasta `cursor-sem-segredos`:

```bash
python3 -m http.server 8765
```

Depois abra [http://127.0.0.1:8765](http://127.0.0.1:8765).

Os arquivos também abrem direto no navegador (`index.html`), porque o texto já vem nos scripts e não depende de um servidor.

## O que tem dentro

- **Básico:** instalar, a tela, Tab, edição inline, a primeira conversa, contexto com `@`, diff e atalhos.
- **Intermediário:** modos Agent, Ask, Plan, Debug e Design, pedidos, regras, modelos, terminal, Git, skills e MCP.
- **Avançado:** Cloud Agents, CLI, subagentes, hooks, Bugbot, times e um jeito de trabalhar quando o agente erra.

O leitor guarda os capítulos lidos neste navegador, troca os atalhos entre Mac e Windows/Linux e tem modo noturno.

## Conferir os capítulos

```bash
node verificar.mjs
```
